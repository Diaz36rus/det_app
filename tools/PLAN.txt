Det App — план внедрения (кратко)
================================
Порядок блоков (без разбивки по дням):

A  Страховка: тесты + домашний смоук + журнал багов   ← ГОТОВО (авто)
B  Логины в приложении                                ← ГОТОВО
C  Полный онлайн → выключить LAN                      ← ГОТОВО + bridge карточки
...
При входе компании старые экраны (Kanban/Clients/Cash/…) работают через CloudDbBridge → API.
Карточка заказа: открытие, позиции, статус, оплата — в REST. Часть фич (оклейка/промо) — no-op до API.
Build 54.
D  Визуал / адаптация мобилки (кусками параллельно)
E  Сайт + фичи роста (в ящике)

Блок B — критерий
-----------------
Вход по email ИЛИ телефону, сессия сохраняется, выход из меню.
Демо: admin@det-app.ru / 9000000001  пароль DetAppAdmin2026!

Блок C — ГОТОВО
---------------
Данные студии в Postgres на Cali. Signed-in company → обычные пункты меню
(доска, клиенты, касса, прайс, сотрудники, склад, календарь, завершённые, цеха)
ходят в /crm и /cash. Пунктов «Облачные …» нет. LAN-хост не стартует.
Статистика — заглушка «скоро».

Демо: owner@demo.det-app.ru / 9000000002  пароль DetAppAdmin2026!
Деплой API: tools\deploy_cali.ps1

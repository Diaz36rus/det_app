# RuStore — тексты и скрины

## Название
Det App

## Краткое описание
Заказы, клиенты и касса для детейлинг-студии — с телефона и с ПК.

## Полное описание
```
Det App — рабочее приложение для детейлинг-студии: заказы, клиенты, услуги и мастера в одном месте.

На доске видно, где какая машина и на каком этапе работа. В заказе — клиент, авто, услуги и кто делает. Рядом календарь, касса, склад и права по ролям: владелец видит всё, мастер — своё.

Можно вести смену с телефона и с компьютера — данные студии общие. Коллегу добавляете кодом или QR.

Для работы нужен вход в аккаунт студии.
```

## Что нового
Сборка без REQUEST_INSTALL_PACKAGES (требования безопасности RuStore). Обновления — через магазин.

## Как наполнить витрину (debug)
1. Войти в студию (лучше отдельную/демо, не боевую).
2. Студия → «Витрина для скринов» → «Сбросить и заполнить».
3. Снять 6 экранов выше.

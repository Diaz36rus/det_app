Det App — домашний смоук (блок A)
=================================
Замена прогона «на работе», пока нет доступа к смене.
Делай перед важным релизом и после крупных правок.
Боевую базу не копируй в тест — для автотестов: tools\run_regression.ps1

Отмечай: [ ] → [x]


0. АВТО
-------
[ ] powershell -ExecutionPolicy Bypass -File tools\run_regression.ps1
    (или: flutter test test/full_regression_test.dart)


1. WINDOWS (portable / D:\DetApp)
---------------------------------
[ ] Запуск только из DetApp\app\det_app.exe (не из build\…)
[ ] Версия в «Обновление» читается (сейчас актуальная с сервера)
[ ] URL манифеста: http://api.det-app.ru/updates/latest.json
[ ] «Проверить» → актуальная или предлагает скачать (без ошибки updater)
[ ] Меню открывается, разделы: заказы / доска / календарь / касса / склад


2. СМЕНА «ДЕНЬ СТУДИИ» (ПК)
--------------------------
[ ] Касса: открыть смену
[ ] Новый клиент + авто
[ ] Новый заказ с 1–2 работами
[ ] Отметить работы выполненными
[ ] Оплата (наличные или безнал)
[ ] Чек-лист выдачи → статус «Выдан»
[ ] Касса: приход/расход без склада
[ ] Склад: позиция видна, единица измерения ок
[ ] Плёнка (если тестируешь): рулон + списание метров в заказ
[ ] Касса: закрыть смену (факт ≈ ожидаемому)


3. ОБНОВЛЕНИЯ / СЕРВЕР
---------------------
[ ] Браузер: http://api.det-app.ru/health → ok
[ ] Браузер: http://api.det-app.ru/updates/latest.json → есть build
[ ] (Опционально) лампочка → «QR на скачивание APK» открывается без overflow


4. ТЕЛЕФОН (если есть под рукой)
--------------------------------
[ ] APK ставится / уже 1.0.1+актуальный
[ ] Обновления: URL облака, не старый 192.168…
[ ] Пока онлайн-данных нет: Хост на ПК → QR/ссылка → телефон клиент
[ ] На телефоне виден тот же заказ, что на ПК (LAN)


5. БАГИ
-------
Если что-то не так — запись в tools\BUGS.txt (шаблон внутри файла).


Критерий «блок A ок для релиза»
-------------------------------
Автотесты зелёные + пункты 1–2 пройдены на ПК.
Пункты 3–4 — по возможности.

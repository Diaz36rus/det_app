Det App — онлайн-сервер (для новичка)
=====================================

ГЛАВНОЕ
-------
Сайт-визитка НЕ нужен.
Нужны: 1) арендованный компьютер в интернете (VPS/VDS)
       2) домен (адрес вида xxx.ru)
       3) на сервере крутится API (мозг для приложения)

Сейчас: ШАГ 1 — ГОТОВО (сервер Cali, Ubuntu 24.04, 2/4/50, Москва).
IP сервера Cali: 135.106.186.90
Домен: det-app.ru — Active, делегирован.
DNS A (@ и api) → 135.106.186.90
Этап 1 ГОТОВ: docker compose Up (db/api/caddy)
Проверка: http://api.det-app.ru/health → {"ok":true,"service":"det-app-api"}
Код на сервере: /opt/det-app

Этап 2 (auth):
  Docs: http://api.det-app.ru/docs
  Login: POST /auth/login
  Platform admin (по умолчанию после сида):
    email из .env PLATFORM_ADMIN_EMAIL (часто admin@det-app.ru)
    password из .env PLATFORM_ADMIN_PASSWORD
  Demo company owner: owner@demo.det-app.ru (тот же пароль, что PLATFORM_ADMIN_PASSWORD)

Канал обновлений:
  Манифест: http://api.det-app.ru/updates/latest.json
  Выгрузка с ПК:
    powershell -ExecutionPolicy Bypass -File tools\publish_cloud.ps1 -Token "ТОКЕН" -Build
  В .env на сервере: RELEASE_UPLOAD_TOKEN=...
  В приложении канал по умолчанию — облако (можно сменить в диалоге обновления).



ШАГ 1. РЕГИСТРАЦИЯ И СЕРВЕР
--------------------------
1) Открой в браузере: https://selectel.ru
2) Нажми «Регистрация» / «Войти в панель»
3) Зарегистрируйся (почта, телефон — как попросит сайт)
4) Подтверди почту/телефон, если попросят
5) Пополни баланс (иначе сервер не создастся).
   Для старта обычно хватает 500–1000 ₽.

ВАРИАНТ А (проще для новичка) — раздел VDS:
6) В панели: Продукты → VDS (или «VPS/VDS»)
7) Создать сервер
8) Выбери примерно:
   - Регион: Москва или Санкт-Петербург
   - ОС: Ubuntu 24.04 (или 22.04, если 24 нет)
   - Конфиг: около 2 CPU / 4 GB RAM / диск от 40 GB
   - Имя: det-app-server
9) Обязательно включи / проверь публичный IP (чтобы был доступ из интернета)
10) Придумай и СОХРАНИ пароль root (или скачай/сохрани SSH-ключ).
    Пароль в чат Cursor НЕ присылай.
11) Дождись статуса Active / Запущен

ВАРИАНТ Б — «Облачная платформа → Серверы»:
   То же самое: Ubuntu, ~2/4/40+, публичный IP, имя det-app-server.


ЧТО ПРИСЛАТЬ МНЕ ПОСЛЕ ШАГА 1
-----------------------------
- IP-адрес сервера (например 95.xxx.xxx.xxx)
- Регион (Москва / СПб)
- ОС (Ubuntu …)
- «Зашёл по SSH» получилось или нет (да/нет)
НЕ присылай пароль root.


ШАГ 2. ДОМЕН (после сервера)
----------------------------
Покупаем .ru у Selectel или REG.RU.
Имя придумай сам (короткое латиницей).
Потом настроим запись: api.твойдомен.ru → IP сервера.


ШАГ 3–4 (делаю я + ты копируешь команды)
----------------------------------------
Установка Docker, запуск API, проверка https://api..../health

Det App — журнал багов (блок A)
===============================
Формат одной записи — копируй блок ниже.

--------------------------------------------------
ID: BUG-001
Дата:
Где: ПК / Android / оба
Сборка: 1.0.1+
Шаги:
  1)
  2)
Ожидание:
Факт:
Скрин/заметка:
Статус: open | fixed | wontfix
--------------------------------------------------


Правила
-------
- Один баг = один блок.
- Без шагов воспроизведения в работу не берём.
- После фикса: статус fixed + номер сборки, где проверил.

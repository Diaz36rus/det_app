Det App — портативная сборка (Windows x64)
==========================================

ЗАПУСК НА РАБОЧЕМ НОУТЕ
-----------------------
1) Один раз установите Visual C++ Redistributable:
   запустите файл  vc_redist.x64.exe  (рядом с этой инструкцией)
   и дойдите до конца установки.

2) Запустите приложение:
   app\det_app.exe
   (важно: запускайте из этой папки; не копируйте только .exe без папки app)

3) Если Windows спросит про неизвестного издателя — «Подробнее» → «Выполнить в любом случае».


ПРОВЕРКА ДОМА (рекомендуется)
-----------------------------
Перед флешкой прогоните пакет в Windows Sandbox или на чистой ВМ:
  unzip → vc_redist.x64.exe → app\det_app.exe
Если там открывается — на работе откроется.


БАЗА И БАГ-РЕПОРТЫ
------------------
Данные лежат НЕ в папке приложения, а в Документах Windows, файл:
  detailing.db

Типичный путь:
  C:\Users\<Имя>\Documents\detailing.db
(иногда подпапка приложения — смотрите Documents после первого запуска)

Чтобы привезти баги/данные домой:
  скопируйте detailing.db на флешку и откройте дома той же версией приложения
  (или подмените свой detailing.db копией с работы — сделайте бэкап своего файла).

Рядом может быть папка backups\ — её тоже можно скопировать.


ОБНОВЛЕНИЕ ВЕРСИИ
-----------------
Скопируйте новую папку app\ поверх старой (или замените целиком).
Файл detailing.db в Документах при этом не затирается.

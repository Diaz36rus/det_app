Det App — портативная сборка (Windows x64)
==========================================

ПЕРВЫЙ ЗАПУСК (ОБЛАКО)
---------------------
При старте откроется приветственное окно:

  1) Войти          — если аккаунт уже есть
  2) Создать студию — вы владелец своей студии
  3) Меня пригласили — введите код студии / отсканируйте QR

Без входа CRM не откроется. Сессия хранится на этом ПК
(файл auth_session.json в Документах приложения).


ЗАПУСК НА РАБОЧЕМ НОУТЕ
-----------------------
1) Один раз установите Visual C++ Redistributable:
   запустите файл  vc_redist.x64.exe  (рядом с этой инструкцией)
   и дойдите до конца установки.

2) Запустите приложение:
   app\det_app.exe
   (важно: запускайте из этой папки; не копируйте только .exe без папки app)

3) Если Windows спросит про неизвестного издателя — «Подробнее» → «Выполнить в любом случае».


ТЕЛЕФОН
-------
Скачайте APK по QR в приложении (Связь → Приложение для телефона)
или откройте: http://api.det-app.ru/updates/android

Приглашение коллеги: QR «Пригласить в студию» → камера телефона
→ «Меня пригласили» → заявка → админ назначает должность.


ПРОВЕРКА ДОМА (рекомендуется)
-----------------------------
Перед флешкой прогоните пакет в Windows Sandbox или на чистой ВМ:
  unzip → vc_redist.x64.exe → app\det_app.exe
Если там открывается — на работе откроется.


ДВА НОУТА (ОБЩАЯ БАЗА)
----------------------
См. файл SYNC_SETUP.txt рядом с этой инструкцией.

Кратко: на главном ноуте кружок связи → «Офлайн · Wi‑Fi» → «Хост».
На втором → вставить URL → «Клиент». Кружок зелёный = связь есть.
Основной режим — облако (api.det-app.ru); LAN — запасной офлайн.


БАЗА И БАГ-РЕПОРТЫ
------------------
Данные лежат НЕ в папке приложения, а в Документах Windows, файл:
  detailing.db
(на клиенте «живые» данные на хосте; локальный файл не общий)

Типичный путь:
  C:\Users\<Имя>\Documents\detailing.db
(иногда подпапка приложения — смотрите Documents после первого запуска)

Чтобы привезти баги/данные домой:
  скопируйте detailing.db на флешку и откройте дома той же версией приложения
  (или подмените свой detailing.db копией с работы — сделайте бэкап своего файла).

Рядом может быть папка backups\ — её тоже можно скопировать.


ОБНОВЛЕНИЕ ВЕРСИИ
-----------------
Вариант А — кнопка в приложении:
  1) Канал по умолчанию: http://api.det-app.ru/updates/latest.json
     (файл update_channel.json рядом с app\)
  2) В меню слева нажмите «Обновить». Сначала будет напоминание проверить
     незакрытые окна и заказы. Затем «Скачать и установить» → табличка
     «Обновление успешно выполнено» → кнопка «Перезапустить».
     Приложение закроется, заменит только папку app\ и откроется снова.
     detailing.db в Документах не трогается.
     Перед заменой делается копия БД в Documents\det_app_backups\pre-update-*.db

Вариант Б — вручную (флешка):
  Скопируйте новую папку app\ поверх старой (или замените целиком).
  Файл detailing.db в Документах при этом не затирается.
  Папку update\ (DetAppUpdate.ps1) оставляйте рядом с app\.

Det App — связь двух ноутов (одна база)
========================================

Идея: один ноут = ХОСТ (хранит базу), второй = КЛИЕНТ (смотрит и пишет на хост по Wi‑Fi).

ПОДГОТОВКА
----------
1) На оба ноута поставьте один и тот же zip (app\det_app.exe).
2) Один раз на каждом: vc_redist.x64.exe (если ещё не ставили).
3) Оба в одной Wi‑Fi студии (не гостевая сеть с «изоляцией клиентов»).

НОУТ A — ХОСТ (ресепшн / главный)
---------------------------------
1) Запустите app\det_app.exe
2) Нажмите зелёный/красный кружок в шапке
3) Выберите режим «Хост»
4) Если Windows спросит про сеть — «Разрешить» (частные сети)
5) Скопируйте URL вида http://192.168.x.x:7878

Ноут A не уводите в сон и не выключайте на время смены.

НОУТ B / ТЕЛЕФОН — КЛИЕНТ
------------------------
1) Запустите приложение (на телефоне — APK)
2) Кружок связи → «Найти хост в Wi‑Fi»
   (если один хост — подключится сам; если несколько — выберите из списка)
3) Запасной вариант: вставьте URL с хоста вручную → «Подключить как клиент»
4) Кружок должен стать зелёным: «Клиент · связь с …»

Проверка: создайте заказ на A — он должен появиться на B (обновите экран).

ЕСЛИ КРАСНЫЙ КРУЖОК
-------------------
- Хост запущен? Режим «Хост», URL скопирован?
- Один Wi‑Fi? IP не сменился (после переподключения снова скопируйте URL)?
- Firewall: Параметры Windows → Брандмауэр → разрешить det_app
  или временно: разрешить входящий TCP порт 7878
- На хосте в PowerShell: ipconfig  — смотрите IPv4 адаптера Wi‑Fi

ВЫКЛЮЧИТЬ СВЯЗЬ
---------------
Кружок → «Один ПК» — каждый снова со своей локальной базой.

ВАЖНО
-----
- Не копируйте detailing.db на общую папку сети с двух ПК сразу.
- Данные общие только пока клиент подключён к живому хосту.
- Токен по умолчанию: det-lan (только для доверенной сети студии).

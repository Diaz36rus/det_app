FAQ

Частые вопросы

Это платно?

Сейчас нет. Закрытый тест для ограниченного круга студий. Тарифы появятся позже — на сайте будет заглушка, пока не откроем.

Как попасть в студию?

Владелец даёт код студии. На сайте: «Приглашение» → код → открыть приложение. Или в приложении: «Меня пригласили».

Windows и телефон видят одни данные?

Да, в облачном режиме через api.det-app.ru. LAN-режим — запасной офлайн в локальной сети.

Как обновиться?

В приложении: меню → «Обновить». Канал по умолчанию — облако. С этой страницы тоже можно скачать свежую сборку.

Где политика конфиденциальности?

det-app.ru/privacy.html — для сторов и спокойствия.

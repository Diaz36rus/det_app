FAQ

Частые вопросы

Это платно?

Сейчас нет. Закрытый тест для ограниченного круга студий. Тарифы появятся позже.

Чем это лучше чатов и Excel?

Слот сразу в календаре, заказы едут по цехам на доске, оплата закрывается в кассе. Windows и Android видят одни данные — не блокнот, не WhatsApp и не «вечером посчитаем».

Как открыть демо?

Скачай Windows или Android, код студии demo, логин owner@demo.det-app.ru. Пароль на странице в блоке «Демо».

Как попасть в студию?

Владелец даёт код. На сайте: «Приглашение» → код → открыть приложение. Или в приложении: «Меня пригласили».

Windows и телефон видят одни данные?

Да, в облаке через api.det-app.ru. LAN — запасной офлайн в локальной сети.

Где взять Android?

RuStore или APK с этой страницы. Сборки из магазина обновляются через RuStore, не облачным APK.

Есть iPhone?

Нативного приложения в App Store пока нет. Веб-версия для iPhone — отдельным этапом, не в этом запуске.

Как обновиться?

В приложении: меню → «Обновить» (облако). С этой страницы тоже можно скачать свежую сборку. RuStore — через магазин.
